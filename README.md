# 🍱 MealMitra

MealMitra is a comprehensive two-sided marketplace designed to connect hostel students with verified local tiffin (home-cooked meal) vendors. It streamlines the entire process of discovering food services, managing monthly meal subscriptions, and tracking daily deliveries.

## 🚀 Key Features

### 👨‍🎓 Customer (Student) Portal
* **Dynamic Discovery:** Browse verified local tiffin vendors, filter by food type (Veg/Non-Veg), and view service areas.
* **Smart Subscriptions:** Request trial, half-monthly, or full-monthly meal plans. 
* **Subscription Management:** Track request statuses (Pending Approval vs. Active) and manage active meal plans.
* **Live Menu Updates:** View the daily lunch and dinner menus automatically synced from the vendor's weekly schedule.

### 🧑‍🍳 Vendor Portal
* **Business Dashboard:** Track active students, daily meal prep counts, and estimated revenue.
* **Request Management:** Review incoming student requests with the power to Accept or Decline new subscriptions based on capacity.
* **Communication Center:** A "Set It and Forget It" weekly menu manager to schedule 7 days of meals, plus a broadcast tool for instant announcements (holidays, price updates).
* **Extras Store:** Manage and sell additional side items (pickles, papads, sweets).

### 🛡️ Admin Command Center
* **Vendor Verification:** A secure gatekeeping dashboard to review new vendor registrations.
* **Approval Workflow:** Admins can check FSSAI documents/hygiene standards and approve vendors to unlock their platform access.

## 💻 Tech Stack

* **Frontend:** React.js, Tailwind CSS, React Router DOM, Lucide React (Icons)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB (Mongoose ORM)
* **Authentication:** JSON Web Tokens (JWT) & bcrypt
